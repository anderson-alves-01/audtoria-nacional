# Receiving Code Review - Auditoria Nacional

1. Read all findings before editing.
2. Restate the technical requirement and verify it against code, contracts, ADRs and policy.
3. Classify each item: accepted, clarification required, or rejected with evidence.
4. Fix one root cause at a time and add or update regression tests.
5. Re-run impacted gates and request re-review for blocking findings.

Do not accept feedback merely to be agreeable. Do not reject it defensively. If feedback changes tax interpretation, security policy, source methodology or production behavior, stop for the corresponding human authority.
