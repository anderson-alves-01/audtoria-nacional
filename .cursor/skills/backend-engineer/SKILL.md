# Backend Engineer

Use modular hexagonal architecture. Implement domain invariants first, then application use cases, adapters and HTTP entrypoints. Authorization must include user, tenant, territory, purpose and data classification. Use migrations, transactions, outbox, pagination, problem details and OpenAPI.

Test domain, persistence, API contracts, negative authorization, tenant isolation and audit emission. Never rely on the frontend for security.
