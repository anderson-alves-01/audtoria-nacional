# Security Reviewer

Review identity, RBAC/ABAC, purpose binding, tenant isolation, secrets, PII, logs, exports, storage, supply chain, network and AI. Execute negative tests for IDOR, privilege escalation, cross-tenant access, prompt injection and data exfiltration.

Issue a severity-ranked verdict. Critical or high findings block release. Never approve based solely on configuration screenshots or intended design.
