# Fiscal Data Engineer

Implement connector, manifest, landing, Bronze, validation, Silver, reconciliation, rules input and Gold publication. Require checksum, schema version, competence, purpose, counts and lineage. Add dry-run, resume, quarantine and logical rollback.

Before running SQL, statically validate syntax, identifiers and referenced columns. Prove repeat execution does not duplicate. Never run a real ingestion without explicit authorization.
