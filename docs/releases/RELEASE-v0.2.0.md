# Release v0.2.0 - Curadoria Superpowers

## Adicionado

- Seis skills de engenharia adaptadas ao projeto.
- Política central de ativação e parâmetros.
- Matriz de skills por fase F0-F7.
- Perfis de TDD para domínio, dados, infraestrutura e UI.
- Limite de três hipóteses de debugging.
- Review em quatro lentes.

## Excluído deliberadamente

- Brainstorming automático.
- Worktrees automáticas.
- Execução paralela/subagentes.
- Loop genérico de execução.
- Merge, descarte e limpeza automática de branches.

Essas capacidades poderão ser reconsideradas após F0/F1, quando o baseline e os contratos estiverem estáveis.

## Compatibilidade

Mantém as oito skills de domínio e as regras da v0.1.0. A governança do projeto possui precedência sobre as skills de engenharia.

## Origem

Metodologia adaptada do projeto `obra/superpowers`, distribuído sob licença MIT: https://github.com/obra/superpowers
