# Release v0.3.0 - SIRTA Municipal

## Objetivo

Transformar o kit de arquitetura v0.2 em uma especificação implementável do produto municipal SIRTA.

## Principais entregas

- Roadmap reconstruído em 11 fases e gates G0-G10.
- Produto, proposta de valor e limites da automação.
- Glossário operacional.
- Agregados, invariantes e estados ortogonais do crédito.
- Matriz de papéis e segregação.
- Plano de cinco sprints para o núcleo local.
- Backlog estruturado v0.3.
- OpenAPI SIRTA v1.
- JSON Schemas de crédito e ocorrência de transferência.
- AsyncAPI inicial de eventos.
- Skills SIRTA Domain, Transfer Reconciliation e IBS/CBS Readiness.
- Checklists de diagnóstico, legalidade e homologação.
- Prompt mestre de implementação v0.3.

## Gates preservados

Dados reais, credenciais, recursos em nuvem, regras jurídicas/tributárias, IAM, custos, ações destrutivas, publicação externa e produção dependem de autorização humana.

## Escopo de implementação autorizado

Somente desenvolvimento local com dados sintéticos, testes, containers e documentação. A release não contém nem autoriza acesso a dados municipais.
