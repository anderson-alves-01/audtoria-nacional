# Glossário de domínio

| Termo | Definição operacional |
|---|---|
| Crédito identificado | Registro importado ou encontrado ainda não validado |
| Finding | Indício produzido por regra ou análise |
| Crédito validado | Crédito cuja existência, origem e situação foram conferidas |
| Valor elegível | Parcela validada que pode compor o denominador do ISR segundo política vigente |
| Crédito constituído | Valor formalizado pela autoridade conforme processo aplicável |
| Dívida ativa | Crédito regularmente inscrito após controle de legalidade |
| Valor recuperado | Recurso efetivamente recebido e conciliado no período |
| Potencial econômico | Estimativa analítica; não é crédito nem autorização para cobrança |
| Ocorrência de transferência | Diferença ou anomalia de repasse a esclarecer; não é dívida tributária |
| ISR | Valor recuperado dividido pelo valor elegível, multiplicado por 100 |
| Run ID | Identificador imutável de execução de carga ou processamento |
| Finalidade de acesso | Motivo autorizado para consultar ou tratar os dados |
| Cadeia de custódia | Histórico verificável de origem, hash, acesso e transformação da evidência |
