# Checklist de homologação

## Produto

- [ ] Critérios de aceite demonstrados.
- [ ] Usuários-chave aprovaram fluxos.
- [ ] Estados e valores estão semanticamente separados.

## Dados

- [ ] Origem, checksum e competência registrados.
- [ ] Totais reconciliados.
- [ ] Quarentena revisada.
- [ ] Reexecução sem duplicidade.

## Segurança

- [ ] Isolamento de tenant testado.
- [ ] Finalidade obrigatória testada.
- [ ] Segregação de funções testada.
- [ ] Logs sem dados sensíveis.
- [ ] Exportações controladas.

## Operação

- [ ] Monitoramento e alertas.
- [ ] Backup e restauração.
- [ ] Runbook e rollback.
- [ ] Responsáveis e suporte.

## Jurídico e administrativo

- [ ] Regras tributárias homologadas.
- [ ] Checklists aprovados.
- [ ] Comunicações aprovadas.
- [ ] Tratamento de dados aprovado.
