# Prompt: preparar release

Não publique automaticamente.

Valide working tree, versão, changelog, migrations, contratos, testes, scans, artefatos, SBOM, infraestrutura, rollback e evidências. Gere `evidence/releases/<version>/verdict.md`. A release só recebe GO quando todos os gates obrigatórios estiverem verdes e a homologação humana necessária estiver registrada.
