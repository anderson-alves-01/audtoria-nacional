# Prompt: implementar uma feature

Implemente a próxima feature pronta do backlog.

- Confirme dependências e contrato.
- Defina cenários Given/When/Then.
- Implemente domínio, persistência, API, UI e observabilidade necessários.
- Inclua testes unitários, integração, contrato, autorização e E2E conforme risco.
- Use apenas dados sintéticos.
- Atualize documentação, contrato e estado.
- Apresente arquivos alterados, comandos executados, resultados, riscos residuais e rollback.
